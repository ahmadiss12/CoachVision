# Play Store assets

Generated assets and copy for the Google Play listing.

| File | Purpose | Spec |
|---|---|---|
| `play-store-icon-512.png` | Store icon | 512x512 PNG |
| `play-feature-graphic-1024x500.png` | Feature graphic (banner) | 1024x500 PNG |
| `store-listing.md` | App name, descriptions, category, Data Safety answers | — |
| `screenshots/` | Phone screenshots, 8 of them | 1241x2444 PNG, 1.97:1 |

The screenshots were captured at device resolution, with the iOS status bar
cropped and the width padded with the app background so the ratio stays under
Play's 2:1 limit.
